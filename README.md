# Docker Status Monitor

Docker 容器状态实时监控面板，基于 Next.js 构建。

## 功能

- 实时监控 Docker 容器运行状态
- Web 可视化面板

## 技术栈

- Next.js 15 + React 19 + TypeScript
- Tailwind CSS v4

## 快速开始

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建
npm run build

# 启动
npm start
```

访问 [http://localhost:3000](http://localhost:3000) 查看面板。
